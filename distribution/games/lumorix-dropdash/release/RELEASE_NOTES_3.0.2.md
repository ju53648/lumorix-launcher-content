# VENSUKO DropDash 3.0.2 — Launcher Achievements

- Achievement popups are now displayed exclusively by VENSUKO Launcher in the lower-right corner of the screen.
- Keep the complete in-game 102-achievement catalog, progress bars, earned status and filters.
- Unlock notifications travel over an account-aware, short-lived local capability channel to Launcher 0.16.4 or newer.
- Local progress and account sync from DropDash 3.0.1 remain intact, including offline run queues and one-time legacy import.
- Core gameplay, modes, leaderboard, soundtrack and existing saves remain unchanged.

**Compatibility:** To see achievement popup overlays, launch DropDash 3.0.2 from VENSUKO Launcher 0.16.4 or newer. Older Launcher versions allow normal gameplay but do not display the centralized popup. Exclusive fullscreen overlays depend on the desktop window manager.
